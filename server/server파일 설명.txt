server.js 파일에 지정된 파일위치는 로컬(localhost) 기준 stageBulder폴더를 root로 지정해서 테스트한 서버 설정 파일입니다.
소스 분석후 원하는 폴더에 맞게 수정해주시면 됩니다.

[ 현재 지정한 폴더 ]
stageBuilder/files/audio  -> 오디오 폴더
stageBuilder/files/video  -> 비디오 폴더
stageBuilder/files/fbx     -> 모션 폴더

[ 필요한 패키지 설정 ]
- multer (파일 업로드)
- cors (크로스 오리진 요청 처리)

설정 후 서버 설정 파일 한번 보내주시면 제쪽에서 필요한 부분은 조치하겠습니다.
